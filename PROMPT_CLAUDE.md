Trabalhe neste repositório para implementar o frontend completo do PrazoAI. Primeiro leia CLAUDE.md e todos os arquivos em docs/frontend. Inspecione o código e os prints em assets/references; use-os somente para design e estrutura, nunca para conteúdo ou ampliação de funcionalidades.
Mantenha React + Next.js + TypeScript + CSS e o foco exclusivo em prazos jurídicos.
Nesta primeira etapa implemente apenas o shell da aplicação, os componentes fundamentais e o dashboard com dados fictícios, alternância Pessoal/Escritório e prioridade visual: urgentes, agenda do dia, intimações para revisão, visão geral.
Use a logo aprovada e proponha um estilo sóbrio/moderno com superfície clara, azul profundo e verde-petróleo. Não reaproveite o design antigo do PrazoAI.
Entregue código funcional, explique o que está simulado e mostre o dashboard para aprovação antes de aplicar o padrão às demais telas. Execute testes, verificação TypeScript e build. Preserve backend e arquivos não relacionados.
Depois da aprovação, execute as etapas documentadas até concluir todos os fluxos do frontend. Não invente regras pendentes; consulte docs/frontend/pendencias.md.
