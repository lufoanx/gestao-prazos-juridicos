# Kit PrazoAI para Claude e VS Code
## Abrir e executar
1. Extraia o ZIP mantendo todas as pastas.
2. No VS Code: Arquivo > Abrir Pasta > gestao-prazos-juridicos-main.
3. Abra um terminal, execute:
   cd frontend
   npm ci
   npm run dev
4. Abra http://localhost:3000.
Requer Node.js 22 LTS e npm. Instalação precisa de internet; npm ci utiliza package-lock.json.
## Conferir
Em frontend: npm test, npm run typecheck, npm run build.
## Claude
Abra a pasta raiz no Claude Code ou forneça o projeto em um ambiente com acesso aos arquivos. Claude de conversa não altera automaticamente o VS Code. Cole PROMPT_CLAUDE.md.
