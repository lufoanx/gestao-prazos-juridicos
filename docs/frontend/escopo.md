# Escopo aprovado
PrazoAI gerencia exclusivamente prazos jurídicos para autônomos e equipes de escritórios. Número do processo, partes e tribunal são campos associados ao prazo, não um módulo de gestão processual.
Frontend completo: acesso, onboarding, ambientes pessoal/escritório, prazos, calendário, intimações com revisão, notificações, perfil, configurações, equipe e assistente demonstrativo.
Fora: financeiro, CRM, jurisprudência, geração de peças, pagamentos, planos comerciais, gestão geral de processos, integração real de IA/Google/email, banco e backend nesta fase.
Logo aprovada: P + marcador temporal, azul profundo/verde-petróleo. Design antigo descartado.
Concluído exige fluxos reais dentro da simulação, não apenas páginas estáticas. Backend e segurança de autorização são futuros; acessibilidade e validação UI já são obrigatórias.
